# QCM — TP N°1 : les variables en Python

QCM interactif auto-corrigé, destiné aux étudiants de 1ʳᵉ année de la Licence Appliquée en Marketing Digital, portant sur le TP N°1 (notions de base de Python : déclaration de variables, types, saisie, conversions, opérateurs).

## Accéder au QCM

**Lien direct :** _à compléter après activation de GitHub Pages_
`https://<bentekayalobna-bit>.github.io/<projet1>/`

Aucune installation n'est nécessaire : le lien s'ouvre directement dans un navigateur (ordinateur, tablette ou smartphone).

## Consignes pour les étudiants

1. Ouvrez le lien ci-dessus.
2. Saisissez votre prénom et votre nom.
3. Répondez aux 20 questions (10 de difficulté moyenne, 10 de difficulté élevée). Vous pouvez naviguer librement entre les questions et modifier une réponse déjà donnée.
4. Vous disposez de **10 minutes**. Passé ce délai, le QCM est automatiquement corrigé avec les réponses déjà saisies.
5. À la fin, votre note sur 20 s'affiche avec le détail question par question.

**Important :** l'ordre des questions et des réponses est tiré au sort à chaque ouverture de la page : deux étudiants ne voient pas le QCM dans le même ordre.

## Mettre à jour le QCM

Pour corriger une question ou en ajouter de nouvelles :

1. Ouvrez `index.html` dans le dépôt GitHub (icône crayon pour éditer, ou téléversez une nouvelle version via **Add file → Upload files**).
2. Repérez le tableau `BANK` au début du bloc `<script>` : chaque question y est définie par sa difficulté (`moyen` ou `difficile`), son énoncé, un extrait de code éventuel, ses quatre propositions et la réponse correcte.
3. Validez la modification (**Commit changes**). La page publique se met à jour automatiquement après une à deux minutes.

## Remarques techniques

- La page ne transmet ni ne stocke aucune donnée : le résultat s'affiche uniquement dans le navigateur de l'étudiant et n'est pas enregistré côté serveur. Chaque étudiant doit donc communiquer sa note (capture d'écran ou saisie manuelle) selon les modalités indiquées en cours.
- Le fichier fonctionne aussi hors ligne si vous le téléchargez et l'ouvrez directement dans un navigateur.
